# TA说「纪念日新增弹窗」脱敏演示

这个示例验证 `edu-pm-workflow` 能否把一个历史问题描述转成可交付、可机械校验的产品材料。

需求本身来自真实历史问题：名称或日期为空、日期非法、或保存接口失败时，新增弹窗仍会关闭，已填写内容也会丢失。这里的 PRD、可点击原型和验收清单均为本轮在 fresh 临时目录中新生成的隔离演示，未用于当时的生产发布，也不代表历史版本的真实界面或实现。

## 示例内容

- `纪念日新增弹窗/需求文档/纪念日新增弹窗-PRD.html`：研发交付用 PRD，成功指标没有真实基线时统一写“待基线确认”。
- `纪念日新增弹窗/流程图/纪念日新增弹窗-flow.html`：保存前校验、保存中、成功/失败与重试分支的业务流程图。
- `纪念日新增弹窗/原型/纪念日新增弹窗-prototype.html`：离线可点击原型，浏览器内模拟字段校验、保存失败、重试与保存成功，不调用真实接口。
- `纪念日新增弹窗/验收清单/纪念日新增弹窗-验收清单.html`：可交互验收清单，覆盖名称为空、日期为空、日期非法、接口失败、失败保留输入，以及成功后关闭并刷新列表。
- `纪念日新增弹窗/沟通记录.md`：记录输入事实、待确认项、章节裁剪和演示边界。

## 章节裁剪

本示例保留业务流程图，因为保存前校验、保存中、保存成功/失败和失败后重试构成明确的分支与状态流转。省略交互流程图，因为全部状态都发生在同一弹窗和列表视图内，没有页面间导航链路。项目信息、版本记录、需求背景、需求目标、需求概述、详细方案和数据埋点继续保留；时序图、上线计划和附录因缺少复杂端侧编排、发布策略或补充材料而省略。

## 安全边界

示例只包含脱敏名称、日期和浏览器内模拟状态。它没有读取 TA说产品代码，没有访问网络、生产服务或真实账号，不含真实用户数据、密钥或生产 URL。未知的日期范围、时区、失败分类、埋点参数和列表刷新异常策略均标记为“待确认”。

## 验证

在仓库根目录运行：

```sh
python3 assets/scripts/validate_prd.py 'examples/tasay-anniversary-modal/纪念日新增弹窗/需求文档/纪念日新增弹窗-PRD.html'
```

预期结果为 `PASS` 且退出码为 `0`。
