# 计算修正与兼容性

## 来源基线

数据与计算基础固定在 Stardew-Profits `bc8b72255e6960360415de9736756496971ccdcf`。原始计算片段与预测函数作为不可变快照保存，用于离线回归。数据和 MIT 许可有哈希校验。

保留原版的季节、收获、生长、售价、种子与肥料成本、职业、食物和加工选项。计算不依赖 D3 或页面状态；输入与返回值彼此隔离。

## 为什么不要求每个结果都等于原版

原版对照只能证明移植没有无意改变，不能证明上游公式正确。本次审查发现了可复现的重复消费和数量不守恒，因此同时保留原版对照与独立手算测试。

已修正：

- 消耗金星原料时错误地再次清空银星数量，造成额外出售收入。
- 随机预测只加工一次收获、零收获仍有加工收入，以及固定多产作物丢失产量。
- 留种、加工和出售余量重复消费同一批原料。
- 有设备限制时覆盖已留种后的可加工数量。
- 植物学家同时产生普通/银/金与铱品质，令可售数量翻倍。
- 咖啡配方的「5 豆 / 杯」与设备容量单位不一致。
- 高等级与加成下品质概率大于 1，以及期望数量被展示取整后丢失的余量。

## 手算回归示例

除特别注明外为 60 块地、夏季第 1 天、无肥料和职业、计种子成本。

| 情景 | 修正后的结果 |
| --- | --- |
| 随机预测啤酒花酿造 | 1,020 份成品；净利润 302,400 g |
| 同上，仅余 1 天 | 0 收获、0 收入；净利润 -3,600 g |
| 随机预测蓝莓酿造 | 720 份成品；收入 108,000 g；净利润 103,200 g |
| 春季防风草罐头，留种补种 | 360 份总产量、150 份留种、210 份加工；净利润 24,000 g |
| 同上，1 台设备，出售余量 | 6 份成品、204 份原料余量；净利润 6,778.224 g |
| 冬季种子，收集者 + 植物学家，不计种子成本 | 216 份铱品质原料，收入 41,040 g |
| 咖啡，1 台酿酒桶，不计种子成本 | 9 杯、消耗 45 豆，成品收入 1,350 g；剩余豆出售另计 |

303 个原版场景仍全部参与对照：4,453 行作物的主要经济结果保持一致，346 行属于明确分类的经济修正。这不是宣称全部对象逐字段一致；新增的数量账、单位和未取整期望值属于有意改进。

## 数量守恒

每种作物都有独立原料账：

```text
总产量 = 留种原料 + 加工消耗 + 原料出售 + 未售原料
```

留种与加工按每次收获记录，不能消费不存在的原料；品质只扣减一次。脱水机按 5 份 / 批，咖啡按 5 豆 / 杯，磨坊甜菜按 1 份原料 / 3 份糖换算。成品数量和原料数量分开返回。

## 仍然存在的模型近似

生长加速、野生种子的平均售价、留种平均产出、设备批次和陈酿假设仍是经济模型，不是完整游戏模拟。加工与陈酿耗时不计入。0 成本时回报率沿用模型显示 0%，不表示这种方案没有利润。每日回报率保留原版对一次性/复收作物的不同摊销口径。

随机预测使用每次调用独立的随机种子，同一设置和种子可重复；重新预测才改变种子。大型预测在 Web Worker 中运行，切换设置会取消旧任务，防止旧结果覆盖新条件。
