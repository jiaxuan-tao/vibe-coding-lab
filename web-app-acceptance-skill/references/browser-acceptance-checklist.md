# 浏览器辅助验收清单

## 开始前

- 明确访问地址、验收环境、浏览器尺寸和关键用户路径。
- 若项目需要登录、模拟数据、密钥或付费服务，先标记为前置条件；不要编造账号或绕过访问控制。
- 页面加载完成后再检查元素、控制台和网络请求。

## 每条关键路径

- 起点页面是否可打开，标题和主要内容是否可见。
- 关键按钮、表单或导航是否产生预期的可见结果。
- 错误、加载、空数据或取消操作是否有明确反馈。
- 返回、刷新或直接访问目标 URL 后，状态是否仍可理解。

## 视觉与可用性

- 宽屏和窄屏下是否存在水平溢出、文本截断、遮挡或不可点击区域。
- 键盘焦点是否可见；表单标签、错误信息和图片替代文本是否缺失。
- 动画是否尊重 `prefers-reduced-motion`；不要只以截图判断交互完成。

## 记录方式

- 对每个失败项记录 URL、操作、实际结果、预期结果和影响等级。
- 对外部 API、第三方登录、真实支付、推送或权限流程，记录为未覆盖，不推断其可用性。
