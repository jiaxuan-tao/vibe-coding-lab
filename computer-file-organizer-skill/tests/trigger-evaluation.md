# 电脑文件整理 Skill 触发评估

## 评估目标

验证 Skill 能被“整理电脑文件”的真实表达发现，同时不会因“收件箱”“整理”“清理”等近邻词误触发邮件、代码结构或磁盘删除任务。

## 应触发

| 提示词 | 原因 |
| --- | --- |
| `帮我整理下载文件夹，先给我看怎么分` | 明确目录与按类型整理 |
| `桌面上文件太乱了，帮我归类` | 典型电脑文件整理场景 |
| `找出这个文件夹里内容完全相同的文件` | 精确重复文件检查 |
| `把下载目录顶层的 PDF、截图和安装包分开` | 明确范围与分类任务 |
| `把刚才那次文件整理撤销` | manifest 撤销场景 |
| `包括子目录一起规划，但不要直接移动` | 显式递归和只读计划 |

## 不应触发

| 提示词 | 应使用的能力 |
| --- | --- |
| `整理我的邮箱收件箱，把广告邮件归档` | 邮件连接器或邮箱整理能力 |
| `清理磁盘，删除半年没用的文件` | 磁盘清理；本 Skill 不删除 |
| `帮我重新设计这个代码仓库的目录结构` | 代码架构与重构能力 |
| `在整台电脑里找到那份合同` | 系统文件搜索能力 |
| `自动监控下载目录，以后都不用问我` | 常驻自动化；超出本 Skill 边界 |
| `备份 Documents 到云盘` | 备份与云存储能力 |

## 边界判断

- “下载收件箱”如果明确指下载目录，可以触发；“邮件收件箱”不触发。
- “找重复文件”可以触发只读计划；“删除重复文件”只能报告本 Skill 不提供删除，并可提议移动到待确认目录。
- “整理项目文件”只有在用户指物理文件分类时触发；如果目标是代码模块与仓库结构，不触发。
- 没有给出目标目录时可以触发，但必须先询问目录，不能自行扫描主目录。
