# Skill 触发边界评估

评估日期：2026-07-30

## 方法

向一个未读取仓库文件的独立代理只提供 `SKILL.md` 的 description 和 12 条请求，让它判断是否加载 Skill，不执行请求。该测试验证描述能否区分用户反馈分析与相邻任务。

## Description

```text
Use when analyzing user interviews, customer feedback, support tickets,
survey free text, app reviews, or feedback files to identify product problems
and opportunities; also use when evidence is duplicated, contradictory,
sampled, or easy to overgeneralize.
```

## 真实执行结果

### 应触发

1. `分析这批用户访谈，找出有证据支持的产品机会。`
   - 结果：加载。
   - 理由：明确要求分析用户访谈，并识别有证据支持的产品机会。
2. `整理应用商店差评，注意重复评论和抽样偏差。`
   - 结果：加载。
   - 理由：应用商店评论属于用户反馈，且明确涉及重复证据与抽样偏差。
3. `这些客服工单里哪些问题应该立即修，哪些需要继续验证？`
   - 结果：加载。
   - 理由：客服工单属于适用材料，并需要判断问题优先级与证据充分性。
4. `比较问卷开放题里的相反意见，不要直接多数投票。`
   - 结果：加载。
   - 理由：问卷开放题属于反馈文本，且需要处理相互矛盾的意见。
5. `读取 feedback.csv，区分记录数和独立用户数。`
   - 结果：加载。
   - 理由：反馈文件和独立来源判断都符合触发条件。
6. `把这些用户反馈整理成产品机会，再给出待补证据。`
   - 结果：加载。
   - 理由：要求从反馈提炼产品机会并指出证据缺口。

### 不应触发

7. `帮我设计一份用户访谈提纲。`
   - 结果：不加载。
   - 理由：这是设计研究方案，不是分析已有访谈证据。
8. `给这个登录页写 UI 文案。`
   - 结果：不加载。
   - 理由：属于文案创作。
9. `评审这份 PRD 是否可以进入设计。`
   - 结果：不加载。
   - 理由：属于 PRD 阶段评审，未涉及反馈材料分析。
10. `检查这个 Web 项目能不能发布。`
    - 结果：不加载。
    - 理由：属于工程交付验证。
11. `帮我修复 CSV 解析代码的报错。`
    - 结果：不加载。
    - 理由：虽然出现 CSV，但任务是代码调试，不是分析反馈内容。
12. `总结这篇行业报告的主要观点。`
    - 结果：不加载。
    - 理由：行业报告不是用户反馈材料，任务也只是摘要。

## 结果

12/12 条判断符合预期。description 能覆盖访谈、工单、问卷、评论和反馈文件，同时没有被“访谈”“PRD”“Web 验收”或“CSV 代码”这些相邻关键词误触发。
