# 台球追分计分台动漫首页改版设计

## 目标

将首页现有写实球房照片替换为更有辨识度的动漫插画，同时保持计分工具的成熟感、可读性和现有操作流程。

## 已确认的视觉方向

- 使用热血运动番风格，采用清晰线稿、赛璐璐上色、动态透视和克制的速度线。
- 人物为三位年轻、帅气的成年男性球友，气质偏竞技番主角，但仍表现为朋友间的追分对局。
- 画面核心是一人俯身瞄准击球、另外两人关注局势，绿色球桌和球杆构成主要视觉动线。
- 删除球桌上的手机，不在插画内出现计分界面、文字、品牌或水印。
- 色彩以台呢绿、深墨绿和暖金色灯光为主，允许少量红色点缀，与现有界面协调。

## 响应式资源

- 桌面端生成独立的 16:9 横版插画，确保三位人物、球桌和击球动作完整可见。
- 手机端生成独立的竖版插画，不使用横版图片的机械裁切。
- 两版保持相同人物关系、服装基调、球房环境和画风。
- 画面底部中央需相对干净且明暗稳定，避免与首页主按钮发生视觉冲突。

## 界面范围

- 保留现有墨绿、金色品牌栏、历史记录入口和主按钮样式。
- 不修改首页信息架构、设置流程、计分流程或历史记录功能。
- 仅替换首页图片资源、相应替代文本、离线缓存清单和 README 预览图。

## 质量要求

- 人物五官、手指和肢体无明显畸形。
- 球杆方向、手架、母球和瞄准关系合理，不出现重复或悬空器材。
- 三位角色均为成年人，不采用儿童化或 Q 版比例。
- 手机与桌面端均保持一屏布局，主按钮和历史入口清晰可用。
- 图片加载后无布局跳动；离线缓存包含两套新资源并清除旧版本引用。

## 验收

- 更新静态 UI 契约测试，确认新资源被引用且旧资源不再出现。
- 使用 Playwright 在手机和桌面视口检查正确资源、首屏高度、图片可见性和主要入口。
- 更新项目 README 截图并完成线上 GitHub Pages 验收。
