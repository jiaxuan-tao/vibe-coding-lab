# Web 应用验收 Skill 设计说明

## 目标

新增一个面向 Codex 的中文 Web 应用验收 Skill。它结合可解释的验收流程和零新增运行时依赖的检查脚本，帮助轻量 Web 项目在交付前发现构建、链接、静态资源与基础交互风险。

## 范围

- 新增顶层目录 `web-app-acceptance-skill/`，包含 `SKILL.md`、`README.md`、`scripts/`、`references/`、测试与上游许可证说明。
- Skill 负责确认验收范围、识别项目可用命令、组织人工或浏览器辅助验收、汇总结果与未覆盖风险。
- 脚本只读取被验收项目：识别常见前端项目配置、列出可用脚本、检查构建产物中的内部链接和本地静态资源。
- 脚本默认不安装依赖、不更改项目文件、不启动长期服务，也不上传数据。
- 对缺少 `package.json`、无构建命令、构建失败、动态路由或外链无法静态验证等情况，输出明确的降级结果，而非宣称通过。

## 非目标

- 不替代项目的端到端测试、无障碍审计或人工产品验收。
- 不为未知框架编写特定测试驱动，不内置账户、云服务、凭证或付费能力。
- 不保证动态渲染、鉴权页面、第三方资源或业务正确性。

## 结构与接口

`scripts/inspect_web_project.py` 接收项目路径，输出 JSON：项目元数据、可用 npm 脚本、候选构建目录与警告。

`scripts/check_static_site.py` 接收静态站点目录，输出 JSON：扫描页面数、内部链接错误、本地资源缺失、跳过项与警告。仅处理静态 HTML 中可确定的本地引用。

`SKILL.md` 先运行项目检测，再按“构建 → 静态检查 → 浏览器辅助检查 → 结论与剩余风险”执行；每一阶段都要求记录命令、结果与未覆盖范围。

## 验收与测试

- 测试覆盖标准 npm 项目识别、缺失配置、构建目录推断、无效 JSON 与路径错误。
- 测试覆盖有效内部链接、缺失页面、缺失静态资源、外链与锚点跳过规则。
- 使用 Python 标准库测试，避免新增依赖。
- 完成前验证前置说明、脚本语法、全部测试、README 本地链接和许可归属。

## 许可与归属

上游参考为 Anthropic 的 `webapp-testing` Skill，采用 Apache-2.0。该版本将作为中文化、面向 Codex 的精简改造版本发布：保留 Apache-2.0 文本、来源链接和变更说明，不将第三方工作表述为完全原创。

## 决策理由

混合式方案以低依赖脚本保证确定性，以 Skill 流程处理不同框架和业务页面的差异；它比纯提示词更可重复，比全自动端到端方案更易维护。
