# 文本对比台实施计划

**目标：** 将用户选定的 text.compare lite 作为底座，交付中文默认、中英文即时切换、黑白灰浅深主题的本地优先 Web 对比工具。

**架构：** 保留 Vite + TypeScript + CodeMirror，以及原有对比、文件读取、IndexedDB、导出模块。增加显式 i18n 字典，禁止翻译用户输入。作为 `text-compare/` 子目录集成到现有 GitHub Pages，不创建新仓库。

**已确认设计：** 双栏编辑为主，手机使用统一视图；工具栏紧凑；红绿仅用于差异语义；保留原版功能，移除无关营销落地内容；保留 AGPL、NOTICE、可见作者署名和当前版本源码入口。

## 全局约束

- 默认 `zh-CN`，可切换 `en`；记忆选择，切换不刷新、不丢当前输入或名称。
- 黑白灰外观；浅色、深色、跟随系统；中文字体有系统回退。
- 所有处理留在当前浏览器，无账号、AI API 或云端存储。
- 分享链接包含原文，复制前明确提醒；历史和保存仅限本浏览器。
- Service Worker 和本地存储使用独立命名空间，不能清理其他项目缓存。
- 对比结果、错误、菜单、记录、帮助和 HTML 报告随界面语言变化；不转换用户文档。
- 发布保留 LICENSE、NOTICE，署名链接 James Patton 和本版本源码。
- 保留已有用户的 AGENTS.md 与 docs/SKILLS_WORKFLOW.md 未提交内容。
