# 黑白主体与语义色实施计划

目标：保持现有布局、数据和浅深色外观，以少量语义色区分状态和图表；不新增 emoji 或装饰性彩色背景。

## 约束

- 黑白按钮、标题、正文、侧栏保持中性；蓝表示进行中/交互，绿表示完成，琥珀表示重要/待关注，砖红表示错误/逾期。
- 股票保持红涨绿跌和正负号；记账收入绿、支出蓝，不把正常支出表示为错误。
- 颜色不是唯一状态依据，保留文字、数值、勾选和图例；浅深色分别校验文字对比度。
- 图表分类颜色按标签固定，不随金额排序变化。
- 只替换程序内置 emoji；不修改用户已有笔记、备份或浏览器存储。
- 桌面副本原地更新，保留启动入口、端口和存储键；替换前留存旧文件备份，不在桌面副本运行时覆盖。
- 只提交 personal-workbench 的本任务改动，不包含其他项目未提交内容。
