# 个人工作台演示模式实施计划

**目标：** 在原有黑白工作台中提供独立、可编辑、可重置的完整演示空间。所有公开信息保留真实采集日期与来源；天气城市为武汉。个人数据保持原样。

**架构：** 通过 `?demo=1` 显式进入；页面重载完成空间切换，避免编辑器草稿和异步请求串空间。演示数据使用独立 localStorage 键；示例工作记录按打开日期平移，公开快照永不平移。沿用现有原生 JavaScript、严格数据校验与静态部署，不增加运行时依赖。

## 执行与验收

- [x] 存储与日期：先添加独立命名空间、种子初始化、跨日平移、异常存储与原始数据不变的测试，再实现 `store.js` 参数和 `demo.js`。
- [x] 完整内容：围绕虚构的知识库问答助手项目填充任务、日程、工作计划、日志、笔记、灵感、提示词、学习、模拟账目和模拟投资；所有集合通过 `normalizeData` 校验。
- [x] 模式交互：先编写浏览器用例，再增加全局入口、模式标识、退出、确认重置、演示备份；默认仍为个人空间。
- [x] 公开快照：核实 AI 资讯来源和发布日期，采集武汉天气，分别标注采集时间和数据时间。演示空间不得依赖远程接口；资料不是实时热榜。接口不可得时如实说明，不伪造。
- [x] 首页与信息：演示首页以今日安排、项目推进、学习、资讯摘要为主；模拟投资仍可从原模块进入，不让无行情占据首页。
- [x] 回归：Node 全套测试、浏览器全套测试；桌面/手机/深色截图；离线重访、日期跨月、路径部署、备份导入导出及个人数据字节不变。
- [x] 交付：中文 README、验证记录、静态构建、本地启动脚本和备用压缩包；仅提交本任务变更，推送并核实线上演示链接。

验收结果：77 项单元测试、93 项本地生产构建浏览器测试、13 项实际线上交互与离线测试通过。应用提交为 `527a453`，详细证据见 [验证记录](verification.md)。

## 关键约束

- 不改写仓库内已有其他项目的变更，尤其 cyber-smoke 与已有部署工作。
- 不增加账号、云端推理、后台采集、关闭网页后的提醒等未经授权能力。
- 模拟交易与账目不是用户真实资产，模拟报价不是公开行情。
- 数据空间的错误、冲突、导入和重置必须沿用失败不覆盖的原则。
- 用户已批准范围与发布，无需为技术细节再次询问；真正无法验证的来源和状态应明确披露。
